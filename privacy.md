# Privacy Policy - Hermes bot

Last updated: 9 October 2026

Hermes bot is a personal assistant tool operated by its owner for his own use. It is not a public service.

## Data accessed
With the owner's consent, the app accesses the owner's own Google Drive files, Google Docs, Google Sheets and Google Calendar, only to perform tasks the owner requests.

## Use of data
Data is used only to carry out the owner's requests. It is not sold, shared with third parties, or used for advertising.

## Storage
OAuth tokens are stored only on the owner's own computer. No Google user data is stored on any external server by this app.

## Google API Services User Data Policy
The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
The owner can revoke access at any time at https://myaccount.google.com/permissions
